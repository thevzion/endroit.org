# Endroit

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Software engineers who use AI coding agents heavily and still care how
software is made. They juggle sessions, providers and repositories; they
re-explain context daily; they distrust both hype and magic-memory claims.

## Product Purpose

This Site presents the proof-carrying message architecture: the candidate
spine `Agents produce. Your workplace compounds.`, the category signal
`Software craftsmanship, for the agentic generation.`, and the promise `The
next agent starts ahead, not over.` The mechanism made tangible is
semantically typed working context and its operation, context resolution:
`Context that knows its place.` The visitor must experience agentic capital
(retain, end the Meeting, change the Occupant, observe what remains) before
the page names it.

## Positioning

Endroit is the local-first framework for Workplace-first software craft. It
turns the context, decisions, methods and bounded reach of human-agent work
into durable agentic capital, so each new agent starts ahead instead of
starting over. The accepted category (Decision 0008) remains `THE
WORKPLACE-FIRST APPLICATION FRAMEWORK`; the spine lines above are candidate
copy under test in this iteration.

## Operating Context

A Meeting is not a Room. A draft is not a Decision. A checkout is not an
owner. A reachable repository is not permission. An Occupant is not the
Workplace. Endroit preserves type, owner, lifetime, state, authority and
relationship, then resolves the smallest relevant composition (Home guidance
+ Desk + smallest Room + activated Equipment + current Meeting) with
unrelated Rooms and unauthorized Sites visibly excluded.

## Capabilities and Constraints

- Editorial rule: no orphan claims. Every material claim resolves punch →
  plain consequence → mechanism → demonstration → source and maturity →
  action. One unfamiliar strategic term per section, plain English first.
- Agentic capital = the durable, owned, legible, actionable capacity that
  remains after an agent leaves. Never: automatic memory, retained
  transcripts, a pile of files, zero-effort compounding. Honest promise: it
  compounds through the work, not after it.
- Same claim boundaries as iteration 023: alpha 0.8.0-alpha.1 published,
  alpha.2 local candidate only, Codex and Claude L1-qualified, no measured
  intelligence or accuracy claims, delivery = observed effect, no private
  paths.
- Verified public links only: endroit.org/install/, endroit.org/roadmap/,
  open-workplace.org/, open-workplace.org/proposal/,
  github.com/thevzion/endroit, github.com/open-workplace/open-workplace.
- Static-first, progressive enhancement, no client framework, keyboard
  complete, 320px, reduced motion, honest without JavaScript.

## Brand Commitments

Voice: exact, technical, emotionally resonant; a beautiful instrument made by
people who care about software craft. The visual grammar must emerge from the
actual system: semantic types, owned addresses, resolver traces, included and
excluded context, lifecycle transitions, provenance and maturity. Forbidden:
generic dark developer-tool template, IDE imitation, fake terminals, matrix
rain, purple gradients, decorative dashboards. Dark or light is chosen by the
concept. Distinct from iterations 017-023 (no Connected Home Atlas, no museum
registrar reuse).

## Product Principles

2. Every widget demonstrates a claim; every claim carries maturity.
3. Exclusion is as visible as inclusion in context resolution.
4. The human triggers every lifecycle transition.
5. Preserve earlier iterations untouched.
